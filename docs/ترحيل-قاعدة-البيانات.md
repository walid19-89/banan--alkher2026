## 1) الخلاصة في ثلاث نقاط

1. **GitHub لا يستضيف قواعد بيانات.** GitHub يقدّم صفحات ثابتة (Pages) ومهامًا مجدولة (Actions) فقط، وليس قاعدة بيانات. لذلك «GitHub» ليس خيارًا لقاعدة البيانات، لكنه يبقى مفيدًا للمهام المجدولة والنسخ الاحتياطي.
2. **Cloudflare D1 ليست PostgreSQL.** هي SQLite؛ نقلها يعني إعادة كتابة 123 استعلامًا و9 دوال و9 محفزات ولوحة التحكم كاملة. عمليًا: أسابيع عمل ومخاطرة عالية.
3. **Neon هو PostgreSQL حقيقي ومجاني دائمًا.** النسخة الكاملة من قاعدة بياناتك استُرجعت اليوم على Neon فعليًا وتم التحقق منها بكل الأرقام. هذا هو المسار الأقل مخاطرة.

## 4) لماذا Neon تحديدًا؟

| المعيار | Neon (مجاني) | Cloudflare D1 (مجاني) | Supabase (الحالي) |
|---|---|---|---|
| نوع القاعدة | PostgreSQL 17 | SQLite | PostgreSQL 15/17 |
| حجم التخزين | 1 GB لكل مشروع | 5 GB | 500 MB |
| الإيقاف عند الخمول | لا يوجد إيقاف؛ الحوسبة تنام وتستيقظ تلقائيًا | لا | يُوقف المشروع بعد أسبوع خمول |
| جهد الترحيل | نفس المخطط والاستعلامات | إعادة كتابة كاملة | — |
| المصادقة | Managed Better Auth (حتى 60 ألف مستخدم) | لا | Supabase Auth |
| تخزين ملفات | 5 GB Object Storage | R2 (منتج منفصل) | Storage |
| دوال خلفية | 1 مليون استدعاء | Workers | Edge Functions |
| النطاقات | تعمل على شبكتك | `workers.dev`/`pages.dev` **محجوبة عندك** | تعمل |

أرقام الخطة المجانية من صفحة Neon الرسمية (أكتوبر 2026): 100 مشروع، 100 ساعة-حوسبة لكل مشروع شهريًا، 1 GB تخزين، 5 GB نقل، 5 GB تخزين كائنات، ومصادقة حتى 60,000 مستخدم نشط شهريًا.

## 10) تحديث التنفيذ (10 نوفمبر 2026)

تمت الخطوات التالية دون أي تغيير على الموقع الحالي أو مشروع Supabase:

### الخلفية الجديدة
- `api/app.ts`: نسخة Node من دالة Supabase Edge بنفس المسارات والواجهة (Hono + postgres.js).
- المصادقة أصبحت محلية: توكن HS256 من `AUTH_SECRET` فوق بصمات bcrypt الموجودة في `auth.users`، مع مسار دخول واحد `POST /auth/login` يقبل البريد أو الهاتف.
- التخزين أصبح داخل PostgreSQL في جدول `public.fund_storage` (المرفقات والشعار والنسخ الاحتياطية) بدل Supabase Storage.
- النسخ الاحتياطية تُنزَّل برابط موقّع مؤقت (HMAC) صالح ساعة واحدة.
- نقطة جديدة `GET /sync` تستخدمها الواجهة للاستقصاء الدوري بدل Supabase Realtime.

### ترحيل قاعدة البيانات
- `supabase/migrations/0014_portable_auth_and_storage.sql`: يضيف `fund_storage`، ويعيد محفز `trg_bootstrap_user_profile` على `auth.users`، ويضيف القيمة الافتراضية للمعرّف.
- تم تطبيقه على قاعدة Neon بنجاح عبر `node scripts/apply-sql.mjs`.

### الاختبارات
- `scripts/test-api.mjs`: 11/11 نجحت محليًا وعلى نسخة Netlify (دخول، جلسة، لوحة، أعضاء، اشتراكات، إيصالات، تقارير، نسخة احتياطية وتنزيلها وحذفها، مهام دورية).
- الواجهة بُنيت بنجاح (`npm run build`) و`npx tsc --noEmit` بلا أخطاء.
